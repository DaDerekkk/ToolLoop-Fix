# 数据分类与边界

- `dev/`：手写模拟开发夹具，已暴露给实现者，不能用作正式测试结果。
- `raw/`：预留真实模型轨迹；未运行模型时不放脚本数据冒充模型数据。
- `processed/`：预留验证后的失败点、候选和偏好对；必须可追溯至 raw/run/快照/验证器版本。
- 脚本策略产生的本轮轨迹保存在各自 `experiments/<run_id>/`，证据类型为 `synthetic_harness`。
- 训练/验证/封闭测试将按模板、接口家族和故障组合分组，而不是仅随机打散实体 ID。
- 未正式冻结 train/dev/test split；禁止声称“无泄漏测试集已经建好”。

每个未来数据版本至少附：生成来源、授权与许可、组 ID、用途、去重规则、SHA256、冻结时间及审核状态。真实用户资料、凭据和外部业务数据不进入本项目模拟夹具。
