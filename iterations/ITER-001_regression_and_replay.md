日期：2026-11-16（Asia/Shanghai）。Owner：root；实现：simulator/root；独立审查：protocol/source_audit。

## 假设与预注册验收
独立审查发现的预算、合法重试、循环归因和记录完整性缺陷应先可复现，再用最小修改修复；已有正常/合法重试/澄清/终止行为不得退化。冻结代码与开发数据应能逐字节重放模拟产物。所有结果仅为工程证据。

## 变更
1. 前缀扣除总工具/交互预算，记录 prefix/continuation/total 与剩余预算；超额前缀拒绝。
2. 模拟工具强制首次尝试 + 最多 2 次 timeout retry，以及最多 3 次 poll；计数随快照恢复，不作为业务进展。
3. 固定前缀旧循环与续跑新循环分开；跨边界新增重复仍检出。
4. 不必要澄清单列并计入提前放弃；必要澄清保留。
5. 工具动作等价比较忽略执行器无语义的顶层元数据，原始 trace 不删字段。
6. 记录器 schema v2 从冻结 inputs 目录运行；验证配置哈希、完整输入/输出清单、必需字段、枚举及状态一致性。区分完整模拟评测与诊断探针产物契约，兼容 v1，不改写历史。
7. 新增重放脚本，从源 run 的冻结代码/数据运行并比较三个原产物 SHA256。

## 仍不支持的结论与限制
- 无真实 Qwen 调用、采样、训练、权重或正式测试；无模型效果/显著性结论。
- 15 个开发夹具不是独立数据集或泛化证据；模拟工具复杂度低于提案最终目标。
- detector 未经至少 200 段人工复核；候选仅单步局部验证，不能直接产出训练就绪偏好对。
- 当前只按 policy/mode 自动汇总；域/类别可从逐例派生，正式统计、成本与 BFCL 均待实现。
- ask_user 后直接读取已覆盖；ask_user 后再定位的路径仍受原始请求检查限制，扩流程前须单独修复。
- 快照/hash 不提供恶意进程隔离或签名证明；外部大数据/模型权重未自动冻结，SIGKILL/断电残留需人工恢复记录。
- manifest kind 与任意命令/配置的模型语义尚未强制关联；不能仅凭 kind=model_inference 宣称真实模型已运行。此问题记为模型阶段前门禁。
